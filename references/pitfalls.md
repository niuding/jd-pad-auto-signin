# 设备端京东自动化：实测踩坑清单

来源：2026-11-09 在一台 Xiaomi Pad 7（2136x3200，Android 16，API 36）
上的完整实操。所有坐标以 2136x3200 为基准，`jd_bean_lib.py` 会按 `wm size` 缩放。

## 环境与入口

- adb 装在 `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`（Google 官方 zip，
  免管理员）。`adb shell input tap` 与 `uiautomator dump` 均生效，
  **无需**开启「USB 调试（安全设置）」。
- 京东包名 `com.jingdong.app.mall`；主框架
  `com.jingdong.app.mall/.MainFrameActivity`；权益中心是 WebActivity/H5，
  WebView 的文本在 `content-desc` 里，`text` 常常为空。
- 「我的」页 →「每日必领」横幅右侧按钮约 (1951, 968) → 权益中心浮层。
  浮层左侧分类：「京豆」约 (173, 2385)。资产「京豆」区约 (550, 577)。
- 底部「我的」标签约 (1877, 3070)。

## 关键判据（不要简化）

| 判据 | 依据 |
|---|---|
| 在「我的」页 | 存在 `content-desc` 匹配 `^\d{3,7}京豆$` 的节点，顺带读出余额 |
| 权益中心加载完 | 节点数 ≥ 80 **且** desc 含「权益中心 / 今日必领权益 / 已选中,推荐 / 签到盲盒奖品已到账 / 做任务解锁刮卡 / 一键领取」之一 |
| 任务面板打开 | desc 含「订阅刮京豆」或「逛免费抽盲盒」 |
| 任务按钮 | 右侧 x1>1200、y1>1000、可点、desc 以「去浏览 / 去完成 / 去刮卡」结尾 |
| 弹窗浏览 8 秒任务 | desc 含「开盒次数」且以「去浏览」结尾，1200<y1<1700 |
| 京豆卡片 | desc 含「京豆」且以「去领京豆 / 立即领取 / 点击领取 / 去签到 / 去领豆」结尾，400<x1<1700、1600<y1<3100 |

半加载的 UI 树只有 19 个节点，此时任何点击都是盲点。一定轮询等待。

## 五个真实故障

1. **连按返回键退穿页面栈**：某次直接把京东退到桌面。改为显式
   `am start -n .../.MainFrameActivity` 回主框架，只在 H5 二级页返回**一次**。
2. **横幅文案轮播**：去领取 / 去抽奖 / 立即领 轮流变，文字匹配会失败。
   改为按区域 `1700<x1<2050, 880<y1<1080` 找可点节点，找不到才用坐标兜底。
3. **H5 未加载就抓树**：见上，`wait_for()` 最多 26 秒，每 1.2 秒重抓。
4. **任务面板在页面跳转后消失**：返回后若面板没了但「全部任务」还在，
   同页重新点开即可；整个权益中心都不在了才走完整导航。
5. **任务挤在屏幕外**：面板内 `swipe 1500,2750 → 1500,1650`，滚动后再扫一遍。
   左侧分类列表滚出可视区时，向下滑一次再找「京豆 \d+」。

## 安全边界的两次实战校验

- 金融分类页有个「立即领取」，实际是**先享后付 / 0 元下单 · 送 3 元券**的开通按钮。
  按钮自身文案不含任何禁用词，光靠按钮 BAN 会漏。因此加了 `risky_page()`：
  整页 desc 出现「先享后付 / 0元下单 / 白条 / 分期 / 信用 / 开通金融服务」时，
  连中性的「立即领取」也不点。
- 带「京豆下单最高抵90%」「下单返豆」「支付补贴」的任务一律跳过；
  「玩一玩四季物语 / 逆袭的旅程」这类要合成 10–20 次的小游戏也跳过。

## 行为特性

- 签到开盲盒：点「一键领取」后弹「签到盲盒奖品已到账」，奖品多为红包/券。
- 京豆签到卡：切到「京豆」分类点「立即刮卡」，提示「签到成功！再签 N 天额外得 X 京豆」。
- **任务列表每次重进都重置回「去浏览」**，状态不持久、可重复做。连续多轮后收益递减，
  脚本用轮次上限 + `done` 集合主动停止，避免风控。
- 刮卡机会来自浏览任务，需在同一面板里点「去刮卡」→ 结果页二次确认 → 关闭 → 返回。

## 结果口径

余额只认「我的」页 `^\d+京豆$` 节点；中途结果页偶尔也能读到，仅记日志不作准。
当日实测：1109 → 1121（+12 京豆），另有 4 元（满9元）、10 元（满10.1元）、
0.7 元无门槛红包券。红包券不计入京豆余额。
